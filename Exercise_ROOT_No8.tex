\bigskip

In one of the previous exercises it was discussed how to determine statistical error of the measurement, e.g. by using the subsampling technique. Statistical errors are unavoidable and typically result from the finite amount of data available for the analysis. However, there are other types of errors which can occur during the measurement, which can originate from the malfunctioning of the detector, corrupted data, etc. These errors are called systematical errors, and, unlike statistical errors, they cannot be suppressed by increasing the size of dataset. Since statistical and systematical errors are fundamentally different, they are reported separately in an experiment.

However, in practice it's not always easy to disentangle statistical and systematical errors. Especially in small datasets, large statistical variations can be wrongly to a certain degree attributed to systematical errors. This problem is resolved with the so-called {\it Barlow test}, which is the subject of this exercise. The text in this exercise is reproduced and adapted with permission, from M. Sc. thesis of Marcel Lesch in Ref.~\cite{Lesch:2021}, while a more detailed exposure can be found in Refs.~\cite{Barlow:2002yb,Barlow:1}. 

The typical analysis in high-energy physics commences with the definition of default event and track selection criteria, which leads to the measurement and statistical uncertainty, $y \pm \sigma$, of some observable of interest. To estimate systematical error, one of the default values in the event or track selection is changed and the analysis is redone with this variation. As such, the results related to this single change of a parameter are referred to as the \textit{trial} (denoted by $y_{\rm trial}$). To study whether the divergence between the trial and the initial default results $y_{\rm default}$ is of significance, their difference is calculated as a first step. It is defined as 
%
\begin{equation}
	\mathit{Diff} = y_{\rm trial} - y_{\rm default} \,.
\end{equation} 
%
To determine its statistical significance, the error of the trial $\sigma_{\rm trial}$ in comparison to the one of the default analysis $\sigma_{\rm default}$ has to be accounted for. The importance of this lies in the statistical influence of the used trials. In general, when a selection cut is tightened, less data is used for the analysis leading to an increased statistical error for the trial, while a looser cut leads to the opposite effect in general. To account for this, the so-called \textit{error on the difference} is used:
%
\begin{equation}
	\mathit{Err} = \sqrt{\left| \sigma_{\rm trial}^2 - \sigma_{\rm default}^2\right|} \,.\label{Eq. Error in Difference}
\end{equation}
%
In the last equation, the minus sign has to be used because the datasets used for the trial and default are correlated to each other as they only differ in one selection criterion while being part of the larger, default dataset. Would the two datasets be uncorrelated to each other, a plus sign would have to be used in Eq.~\eqref{Eq. Error in Difference}.
Given the difference and the error in difference, the so-called $\sigma_{\rm Barlow}$ can be computed as 
%
\begin{equation}
	\sigma_{\rm Barlow} = \frac{\mathit{Diff}}{\mathit{Err}} \,.
	\label{eq:barlow}
\end{equation}
%
The $\sigma_{\rm Barlow}$ quantifies the statistical significance of the performed trial. If it is found to be greater than a certain value, the trial is classified as a statistically relevant deviation. In this exercise, a critical value of $\sigma_{\rm Barlow} = 2$ is used i.e. every trial with $\sigma_{\rm Barlow} > 2$ is counted as statistically important. 

As a last step, the systematical error has to be computed. For this, the so-called \textit{relative variation} is used and systematical error is computed as 
%
\begin{equation} 
	\sigma_{\rm sys} = \frac{\mathit{Diff}}{y_{\rm default}}\,.
\end{equation}
%
In case more independent trials have been performed, the final systematical error of all trials is then obtained as the square root of all the individual statistical errors added in quadrature.

\noindent Consider the univariate function $f(x)$ defined by the following formula:
% 
\begin{equation}
	f(x) = Nxe^{-x}\,\quad x\in [0,1),
	\label{eq:definition-f}
\end{equation}
%
where $N$ is normalization constant.
